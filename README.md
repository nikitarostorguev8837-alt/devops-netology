###Файлы будут проигнорированны:  

.terraform/ — папка с загруженными провайдерами и модулями  
*.tfstate — файл текущего состояния инфраструктуры  
*.tfstate.* — бэкапы и другие версии файлов состояния  
crash.log — лог ошибок при падении Terraform  
crash.*.log — логи падений с меткой времени  
*.tfvars — файлы с переменными (пароли, ключи, секреты)  
*.tfvars.json — JSON-версия файлов с переменными  
override.tf — файл локального переопределения ресурсов  
override.tf.json — JSON-версия файла переопределения  
*_override.tf — любые файлы переопределения ресурсов  
*_override.tf.json — JSON-версии любых файлов переопределения  
.terraform.tfstate.lock.info — временная блокировка состояния при применении  
.terraformrc — конфигурация CLI Terraform в домашней папке  
terraform.rc — альтернативный конфигурационный файл CLI
